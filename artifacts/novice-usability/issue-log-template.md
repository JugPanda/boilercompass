# BoilerCompass novice-usability issue log

Use one row per observed issue. Do not merge distinct causes merely because they occur on the same route.

## Priority scale

- **P0 — Safety/blocker:** crisis guidance, trust, destination, or access problem that could cause harm or prevents a core task.
- **P1 — Major:** repeated task failure, wrong first click, or severe misunderstanding affecting multiple participants.
- **P2 — Moderate:** recoverable friction, hesitation, or unclear language.
- **P3 — Minor:** polish issue with little effect on completion.
